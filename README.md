# PIXELENT Tools - releases

PIXELENT Tools 배포 파일 (exe) 저장소입니다. 프로그램은 이곳의 최신 Release 로 자신의 업데이트를 확인하고, modules.txt 로 설치할 수 있는 도구 목록을 받습니다.
Release binaries of PIXELENT Tools. The program checks the latest release here for its own update and reads the tool list (modules.txt).

각 Release 의 파일 / Files in each release:
- SHA256SUMS.txt (+ .sig) : 버전과 exe 의 SHA-256 (서명됨) / version and SHA-256 of the exe files (signed)
- modules.txt (+ .sig) : 설치할 수 있는 도구 목록 (서명됨) / list of installable tools (signed)
- PIXELENT_Tools_x64.exe / PIXELENT_Tools_x86.exe : 64비트 / 32비트 Windows
